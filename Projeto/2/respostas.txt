--------------------------

   console.log("Maior de idade");
} else {
   console.log("Menor de idade");
}

-------------------------

Após analisarmos ele conseguimos chegar a conclusão que esse trecho de código é um verificador simples de idade, agora responda abaixo:

a) O que será exibido?

Será exibido "Menor de idade".

b) O que precisa mudar para aparecer "Maior de idade"? 

Mudar a atribuição de idade para 18 ou mais.
